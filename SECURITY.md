# Security Policy

## Supported Versions

Only the latest commit on the default branch is actively supported.

| Version | Supported |
|---------|-----------|
| Latest (default branch) | Yes |
| Older commits | No |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report security issues via email to **lxveace@proton.me** with:

- A clear description of the vulnerability
- Steps to reproduce
- Potential impact assessment
- Any suggested mitigations (optional)

You can expect an acknowledgement within 72 hours. Responsible disclosure is appreciated — please allow reasonable time to assess and address the issue before any public disclosure.
